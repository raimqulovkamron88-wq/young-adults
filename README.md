# Young Adults Kids

React + Vite + Firebase Authentication loyihasi.

## Ishga tushirish

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
```

Firebase sozlamalari uchun `README-FIREBASE-SETUP.md` faylini o‘qing. `.env` faylini loyiha ildizida o‘zingiz yarating; u Git'ga qo‘shilmaydi.

Eslatma: hozirgi o‘yin progressi lokal qurilmada saqlanadi. Ko‘p qurilmali sinxronlash va mukofotlar xavfsizligi alohida backend ishini talab qiladi.
